# No Overtime Pet（不要加班）

一款 Windows 联机工作桌宠：用户只录入任务名称、DDL 和重要性，系统分析任务类型、预计时长与认知负荷，生成当天可调整的工作安排，帮你把该做的事做完并**准点下班**。

工作时，像素角色会根据键盘、鼠标、会议、浏览内容、离位等真实状态播放动作；已互加好友的用户可以在“排排坐工作”界面看到彼此的泛化状态与同步动作。

> 当前阶段：**PRD 与技术方案**。仓库内暂无工程实现代码。

## 核心机制

```text
录入任务 ──> AI 建议(类型/时长/负荷) ──> 用户确认排程 ──> 工作中桌宠动作
                                                          │
   好友排排坐(仅泛化状态) <────────────────────────────────┘
                                                          │
   准点跑路 ──> 窝囊费结算 ──> 商店买角色/叠帽子 <─────────┘
```

- **窝囊费**：唯一货币，按用户填写的人民币日薪与工时累计，午休暂停，加班倒扣。
- **加班奖励池**：加班倒扣的钱不销毁，进入待结算池，分给当天准点下班且完成承诺待办的用户。
- **购买力守恒**：商品定价基于“工作时长”，再按用户单位时间窝囊费换算，避免高薪套利。
- **用户 > AI**：AI 只出建议，用户的锁定、排序和时长永远优先。
- **隐私优先**：好友只能看到泛化状态，不传截图、按键值、窗口标题、任务正文或日薪。
