# 00｜产品总览

## 1. 一句话定义

《不要加班》是一款 Windows x64 像素风联机工作桌宠：AI 帮用户把今天该做的活排好，桌宠把真实工作状态演成荒诞动作，用户以“完成承诺待办并准点下班”为每日胜利。

## 2. 产品目标

1. 降低“今天先做什么、还能不能准点走”的规划负担。
2. 让重复工作过程具有轻松、可见、可与朋友共鸣的游戏反馈。
3. 用真实个人节奏持续校准任务时长，而不是追求统一的效率标准。
4. 让准点下班成为正向结果，让免费加班产生直观损失。

## 3. 价值取舍

| 冲突 | 优先项 |
|---|---|
| 用户判断 vs AI 判断 | 用户判断 |
| 识别准确度 vs 模型调用成本 | 准确度，但必须取得授权并提供本地模式 |
| 功能闭环 vs 复杂办公室表现 | 功能闭环 |
| 好友趣味 vs 暴露工作内容 | 隐私 |
| 自己工作所得 vs 工资数值差异 | 自己工作相同时间保持相同购买力 |
| 加班公共池 vs 跨工资福利 | 按实际人民币扣款入池，允许高工资加班惠及低工资获奖者 |
| 按时下班 vs 强制完成全部任务 | 用户可自由跑路，系统只如实结算胜负 |

## 4. 核心用户

- 日常使用 Windows x64 电脑办公的知识工作者；
- 有多个并行待办但不愿手工安排时间块的人；
- 希望和少量真实朋友共享上班状态、但不希望暴露内容的人；
- 喜欢桌宠、像素角色和轻度收集装扮的人。

不以企业管理者、员工监控或绩效考核为目标用户。

## 5. 每日核心流程

1. 用户使用用户名和密码登录，读取自己填写的工时、午休和日薪。
2. 用户录入当天待办：标题、DDL、重要性；创建后自动进入 AI 分析。
3. AI 给出任务类型、预计时长、认知负荷、拆分和排程建议，用户点击“确认建议”。
4. 用户接受或修改建议，形成当天承诺快照与正式日程。
5. 工作期间，桌宠根据键鼠、前台应用和可选视觉识别播放动作。
6. 好友在一排工位中看到“认真工作 / 开会 / 摸鱼 / 离开”等模糊状态。
7. 有效工作时段累积窝囊费；午休暂停。
8. 到下班时间，用户点击“跑路”；继续在线则窝囊费开始减少。
9. 当天完成承诺待办且准点跑路者获得胜利，并有资格均分加班奖励池。
10. 用户用窝囊费购买角色和帽子，帽子可垂直叠加。

## 6. 每日胜负定义

### 6.1 胜利

同时满足：

- 当日承诺快照中的必要任务全部完成；
- 在下班截止时间加允许缓冲前完成“跑路”；
- 当日存在至少一个有效承诺任务；
- 会话未被风控标记为不可结算。

### 6.2 非胜利状态

| 状态 | 说明 |
|---|---|
| `TASKS_INCOMPLETE` | 准点跑路，但承诺任务未全部完成 |
| `OVERTIME` | 任务可完成或未完成，但超过截止仍未跑路 |
| `NO_COMMITMENT` | 当天没有有效承诺任务，不参与奖励资格 |
| `UNVERIFIED` | 会话数据不足或被风控拦截，不参与结算 |

产品不阻止用户在任务未完成时下班，也不使用羞辱性强提示。

## 7. MVP 范围

- Windows x64 Demo 启动、用户名密码登录、系统托盘常驻与透明桌宠窗口；
- 工时、午休、日薪设置；
- 待办录入、AI 分析、日程建议和用户确认；
- 本地前台应用、输入活跃度和可选截图识别；
- 预制角色动作、拍键盘、离开工位等基础状态；
- 注册、加好友、好友排排坐及实时状态；
- 窝囊费账本、准点/加班规则、奖励池结算；
- 角色与帽子商店、帽子叠加；
- 隐私授权、账号注销和识别降级。

当前只交付可分享 Windows x64 Demo。代码签名、安装器、自动更新、公开下载渠道和 SmartScreen 信誉不进入本阶段；macOS 客户端暂停。

## 8. 非目标

- 不做项目管理套件、团队任务分派和企业管理员面板；
- 不做精准工时审计或薪资发放；
- 不做社交广场、陌生人聊天和公开排行榜；
- 不做自由移动的虚拟办公室或元宇宙；
- 不读取按键内容，不上传原始桌面内容给好友；
- 不保证 AI 计划永远正确，必须允许用户修改。

## 9. 成功指标

| 指标 | 定义 | MVP 观察目标 |
|---|---|---|
| 日计划确认率 | 生成建议后形成正式日程的工作日比例 | 建立基线，不设激进目标 |
| 时长校准误差 | `abs(实际-预计)/实际` 的中位数 | 连续使用后下降 |
| 准点跑路率 | 有有效工作日中准点跑路的比例 | 建立个人趋势，不做用户间排名 |
| 任务完成且准点率 | 同时满足每日胜利条件的比例 | 核心健康指标 |
| 状态识别准确率 | 用户标注与系统分类一致比例 | 宏观分类 Top-1 ≥ 85%（待样本验证） |
| 好友状态延迟 | 本地动作到好友客户端显示的 P95 | ≤ 3 秒 |
| 奖励池守恒差异 | 入池人民币分与发放+余量的差 | 必须为 0 分 |

## 10. 体验原则

1. 荒诞但不羞辱：文案可以自嘲，不评价用户价值。
2. 看得懂：用户随时知道 AI 为什么这样排、窝囊费为什么变化。
3. 可确认：AI 预计和日程必须经用户确认；活动识别结果只读，错误或低置信时降级为中性状态，用户可暂停识别但不回写分类。
4. 低打扰：桌宠动作有趣，但提示默认不遮挡工作。
5. 隐私默认收敛：朋友只看到模糊状态；截图识别必须单独授权。
