# 12｜通知、权限与隐私

## 1. 目标

以最少打扰的方式提醒待办和跑路时间，同时让用户清楚控制桌面识别、截图上传、好友状态和数据留存。

## 2. 权限分层

不得使用一个笼统“同意所有权限”开关。至少分为：

| 权限 | 默认 | 说明 |
|---|---|---|
| Windows 前台应用类别 | 询问后开启 | 仅派生类别 |
| 键鼠活跃度聚合 | 询问后开启 | 不采具体键值/坐标 |
| 本地窗口标题分析 | 关闭 | 原文只在本机内存 |
| 浏览器类别 | 关闭 | 不保留完整 URL |
| 在线截图视觉识别 | 关闭 | 单独授权、先打码、无留存 |
| 好友状态广播 | 好友功能开启时询问 | 只广播模糊状态 |
| 系统通知 | 询问 | 可按类型关闭 |

撤销权限后立即停止对应采集；已有派生数据可从设置页删除。

## 3. 首次引导

建议分时询问：

1. 首次运行只请求账号、托盘和基础通知；
2. 用户启用桌宠动作时解释并请求输入聚合/前台应用；
3. 用户选择“高准确识别”时才请求截图上传；
4. 用户添加首个好友时确认广播范围；
5. 每个权限页展示“采什么、不采什么、发给谁、保存多久”。

## 4. 通知类型

| 通知 | 默认 | 示例 |
|---|---|---|
| 下一个任务开始 | 开启 | “该换下一摊活了” |
| DDL 风险 | 开启 | “照这个速度，可能赶不上 DDL” |
| 午休开始/结束 | 开启 | “窝囊费暂停，先去吃饭” |
| 下班提醒 | 开启 | “可以跑路了” |
| 加班扣减 | 开启，低频 | “窝囊费正在倒扣” |
| 好友成功跑路 | 关闭 | 避免社交通知泛滥 |
| 商店上新 | 关闭 | MVP 可不实现 |

加班提醒最多按策略低频出现，不得每分钟弹窗施压。

## 5. 数据最小化与留存

| 数据 | 建议留存 |
|---|---|
| 原始截图 | 0；请求完成立即释放 |
| 具体窗口标题/URL | 默认 0；不落盘 |
| 本地活动特征 | 7 天滚动，可关闭 |
| 活动分类与用户纠错 | 90 天或用户删除 |
| 任务和日程 | 用户主动删除前 |
| 经济账本 | 依法务/审计策略长期保留，前台可导出 |
| 好友 presence | Redis 短 TTL，不作为历史轨迹 |
| 安全审计日志 | 建议 30–90 天，去内容化 |

具体留存期限上线前需法律与隐私评审。

## 6. 好友可见性

用户可选择：

- 正常广播：状态、动作、装扮、是否跑路；
- 模糊广播：只显示在线/离开/跑路；
- 隐身：显示离线。

无论何种模式，任务标题、工资、余额、DDL、应用和窗口内容都不可见。

## 7. 在线模型供应商要求

- 提供关闭数据训练/留存的企业或 API 模式；
- 传输加密；
- 记录供应商、区域、modelVersion 和调用目的，不记录图片本身；
- 供应商变化需更新隐私说明并重新评估；
- 不把视觉模型输出的 OCR 文本写入日志；
- 请求失败时不得自动切换到隐私条款更宽松的供应商。

## 8. 用户数据权利

- 查看和修改个人设置；
- 导出任务、日程、经济账本和好友关系；
- 删除活动识别历史和个人学习特征；
- 注销账号；
- 注销后立即停止联机展示，后台按政策异步删除或去标识化；
- 经济账本如因审计需要保留，应与可识别账号解绑并在政策中说明。

## 9. 安全要求

- Windows 凭据用系统安全存储；
- 本地 SQLite 中敏感字段加密或使用受限密钥；
- 服务端传输 TLS；
- 服务端按用户和好友关系授权，不相信客户端字段过滤；
- 日薪、任务和账本不得进入普通埋点；
- 错误上报前做字段级脱敏。

## 10. 验收条件

1. 截图识别未授权时无截图网络请求。
2. 撤销输入权限后 1 秒内停止采集。
3. 好友状态抓包只含共享契约允许字段。
4. 原始截图、窗口标题和 URL 不出现在日志、Sentry 或数据库。
5. 隐身后好友在 3 秒内看到离线。
6. 用户可删除活动历史，删除后 AI 不再使用该历史。
7. 每项权限都有独立开关和清晰说明。

## 11. 待确认项

`[待确认: ACTIVITY-PRIVACY-001][阻塞]` 高准确截图权限的引导时机。  
`[待确认: PRIVACY-001][阻塞]` 目标发行地区及对应法律要求。  
`[待确认: PRIVACY-002]` 本地活动分类默认保留时长。建议 7 天特征、90 天纠错。  
`[待确认: NOTIFY-001]` 加班扣减提醒频率。建议首次扣减时一次，之后每 30 分钟一次。

## 12. 依赖

- 活动识别；
- 好友实时状态；
- 工作日通知；
- 账号和数据删除 API。
