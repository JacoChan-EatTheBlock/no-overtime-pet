# 17｜待确认问题台账

> 本文件同时保留已确认结论与剩余 `[待确认: ID]`。具体语境和业务规则仍以对应模块为准。

## 1. 使用规则

- `P0`：开始对应核心实现前必须确认；
- `P1`：可按建议值做原型，但正式上线前确认；
- `P2`：不阻塞 MVP 核心闭环，可延后；
- 确认后，应把对应模块标签改为 `[已确认]`，同时在本表记录结论和日期；
- 开发 AI 不得把“建议默认值”伪装成用户已确认决定。

## 8. 已确认且不应重复提问

| 决定 | 当前结论 |
|---|---|
| 首发平台 | macOS；Windows 延后，不属于 MVP 发布承诺 |
| 首版 CPU 架构 | Apple Silicon `arm64`；Intel Mac 暂不承诺 |
| 首发分发方式 | 官网 DMG；Developer ID 签名并经 Apple 公证 |
| 首发区域与时区 | 仅中国大陆；业务日期固定 `Asia/Shanghai` |
| Mac App Store | 不进入 MVP |
| 视觉风格 | 像素风 |
| 动画管线用途 | 只生产资源，不进运行时代码 |
| 桌宠角色 | 预制角色与动作包 |
| 桌面识别成本取舍 | 准确度优先，但截图需单独授权 |
| 待办最少字段 | 标题、DDL、重要性 |
| 新建待办分析流程 | 创建后自动进入 AI 建议确认；列表无逐条分析按钮 |
| AI 权限 | 建议任务类型/时长/认知负荷，用户优先 |
| AI 建议主操作 | 使用“确认建议”写入用户接受或修改过的字段 |
| 登录方式 | 用户名 + 密码；不使用邮箱、手机号、验证码或离线体验 |
| 账号页范围 | 不提供设备管理、数据导出或退出其他设备；账号与计划数据以服务端为准 |
| 活动识别交互 | 结果只读，可暂停或关闭；不提供活动纠正入口 |
| 好友单向隐藏 | 使用“不对其展示”，保持好友关系，不提供拉黑能力 |
| 桌宠可见性 | 活动广播与本机好友桌宠显示为两个独立复选设置 |
| 登录页动画位 | 128×128 “金币砸脑壳”透明循环 GIF；缺失时静态关键帧降级 |
| 工资与时间 | 用户填写日薪、上下班、午休，系统不推断 |
| 联机范围 | 注册后互加好友 |
| 场景复杂度 | 简单排排坐，不做复杂虚拟办公室 |
| 用户货币 | 只有窝囊费 |
| 处理币种 | 只处理人民币，不做外币和汇率换算 |
| 商品公平定价 | 固定价格窝囊时长 × 用户单位时间窝囊费 |
| 加班扣减去向 | 实际扣除的人民币窝囊费原额进入准点完成者奖励池，不按工资率换算 |
| 多名获奖者 | 按人民币最小单位“分”平均分配，余数结转 |
| 跨工资奖励效果 | 高工资用户加班可给低工资获奖者带来更高购买力福利 |
| 帽子玩法 | 可持续向上叠加，不设固定装备数量硬上限 |
| 帽子超高交互 | 不自动缩小，直接纵向滚动 |
| 角色动作格式 | 128×128 透明 GIF；`PetAction` 状态机切换并重启对应 GIF |
| App 计提边界 | 只有 App 打开、已登录且连接时计提；离线区间不计提 |
| 断线结算 | 截止前重连恢复资格；截止时仍断线则当日所得转池 |
| 奖励池期限 | 无人领取全部滚存；每笔首次入池后 7 个北京时间自然日过期 |
| 单人奖励 | 单一合格玩家可以独自领取全部可分配余额 |
| 截图识别 | 产品开关默认开启，但系统授权前不得采集或上传 |
| 任务标题分析 | 允许交给已披露的在线大模型；不做跨用户聚合基线 |
| 密码恢复 | MVP 不提供任何找回或恢复能力 |
