# 15｜测试与验收总则

## 1. 发布门禁

MVP 发布前必须通过：

1. 单元测试；
2. API/事件契约测试；
3. 数据库集成测试；
4. Windows x64 Demo 端到端关键路径；
5. 经济守恒与幂等测试；
6. 隐私数据泄漏检查；
7. AI 离线评估；
8. 动画资产自动 QA；
9. 性能与断网降级检查。

任何“通过”都必须记录命令、环境、版本和报告位置。静态检查通过不等于真实 Windows 输入钩子、截图、托盘、透明窗口、混合 DPI 或另一台机器上的 Demo 启动已验证。

## 2. 单元测试

### 2.1 时间与工时

- 正常 9:00–18:00、午休 12:00–13:00得到 8 小时标准带薪时长；
- 午休边界不重复计提；
- 上班前、午休、下班后 phase 正确；
- IANA 时区转换覆盖夏令时日期；
- 非法时间顺序拒绝；
- MVP 跨日班次明确拒绝。

### 2.2 窝囊费

- 钱包显示四舍五入规则；
- 商品显示价向上取整；
- 工资/工时同比变化不改变可购买商品集合；
- 负数余额显示 `[待确认]`；
- 账本 delta 与 balanceAfter 连续一致；
- 加班人民币扣减使用累计差值，分段计提与整段计提得到相同入池金额；
- 奖励入账后修改日薪，不会再次放大既得购买力。

### 2.3 任务与排程

- 紧急性各边界；
- 用户覆盖字段不被 Proposal 覆盖；
- 相同输入相同策略得到确定性 Draft；
- 午休、固定事件、DDL、锁定块不冲突；
- 容量不足明确返回 unscheduled。

### 2.4 动作与事件

- 按键只产生左右手意图，不保存键值；
- 高频动作按窗口聚合；
- 状态优先级和 fallback；
- 事件 sequence 去旧；
- TTL 过期回到安全动作。

## 3. 经济关键测试场景

### E-001：单人奖励

用户 A 每小时窝囊费 100 元，加班 30 分钟；用户 B 完成承诺且准点跑路。预期：A 实际扣除 50 元，池增加 5000 分，B 实际领取 5000 分，余量 0。

### E-002：多人平均

总池 6000 分，B/C/D 三人符合。预期每人领取 2000 分，不按收款人工资比例改变人民币份额。

### E-003：无法整除

池为 1001 分，两人符合。预期每人领取 500 分，余 1 分结转。

### E-004：不同工资

高工资用户 A 加班实际贡献 10000 分，低工资用户 B 单独符合。B 每小时窝囊费 50 元。预期：B 实际领取 10000 分，可获得 2 小时商品购买力；不得把 A 的贡献先归一化为 A 的 1 小时再发给 B。

### E-005：高工资套利失败

先高日薪积累自己的工作收入、再改低日薪、购买固定 2 小时商品，预期自有购买力不变。另验证 B 在 50 元/小时费率下领取 100 元奖励并固化为 2 小时购买力后，把工资改为 100 元/小时，仍只有 2 小时购买力，不会再次翻倍。

### E-006：幂等重放

同一计提、购买、跑路和结算请求各重放 10 次。预期每个业务结果只发生一次。

### E-007：并发购买

余额只够一件商品，同时发起两笔购买。预期一笔成功、一笔余额不足，不出现负购买透支。

### E-008：任务删除作弊

冻结快照含任务 X，用户未完成并在结算前删除 X。预期不具备资格，取消记录可审计。

### E-009：无人符合

按 `ECON-POOL-002` 选定策略验证人民币分滚存或其他明确结果；不得出现资金消失。

### E-010：崩溃恢复

扣减账本写入后服务崩溃。预期同事务已生成完全相同人民币金额的贡献，或整体回滚；不能只扣不入池。

### E-011：池内禁止等价时间均分

构造两笔相同加班时长但工资不同的贡献。预期池增加两笔不同人民币金额，其总额按分均分；任何结算输入或输出都不存在 `equalShareEquivalentMs`。

## 4. API 契约测试

- OpenAPI Schema 与共享 TS 类型语义一致；
- 必填/可选、枚举、整数范围和时间格式错误均返回稳定错误码；
- revision 冲突不覆盖新数据；
- 幂等键同 payload 返回同结果，不同 payload 返回冲突；
- 所有列表使用游标分页；
- 旧客户端遇到新可选字段不失败。

建议服务端和客户端使用同一生成 Schema 包，但运行时仍做边界校验。

## 5. 隐私与安全测试

### 5.1 静态检查

扫描日志、Sentry payload、WebSocket Schema、数据库列和埋点，禁止：

- `keyCode`、`scanCode`、具体按键；
- 鼠标绝对坐标；
- 原始 screenshot bytes；
- window title、完整 URL、文档正文；
- task title、salary、wallet 出现在好友事件。

### 5.2 动态检查

- 未授权模式抓包无截图请求；
- 撤销权限后采集线程停止；
- 敏感页面命中黑名单时不截图；
- 删除好友后双方无法继续订阅；“不对其展示”只撤销当前用户到目标好友的单向投影；
- token 失效后网关断开；
- 显示名和安全文案无法注入 HTML。

## 6. AI 评估

### 6.1 任务分析

- 分类 Macro-F1；
- 时长 MAE、Median APE、P90 APE；
- 估计区间覆盖率；
- 按工种、任务类别、样本量切片；
- 连续使用后的个人误差是否下降；
- 用户覆盖字段保留率必须 100%。

### 6.2 活动识别

- 宏观分类 Macro-F1 目标 0.85，正式门槛以首轮数据评估确认；
- `AWAY`、`MEETING`、`SLACKING` 单类 recall；
- 状态切换延迟；
- 敏感页面拒绝截图 recall 应接近 100%；
- 本地模式与高准确模式分别报告，不能混成一个平均值。

模型或策略版本变化必须重新跑固定 holdout 集。

## 7. Windows x64 Demo 端到端

覆盖当前 Windows 开发机，并在条件允许时增加另一台 Windows 11 x64 机器，至少测试：

1. 从全新解压目录或干净 checkout 启动 Demo、首次运行、退出、再次启动和用户数据保留；
2. Demo 文件清单、版本/commit 记录与发行产物 SHA-256；
3. 开机启动开关、系统托盘常驻、主窗口关闭与明确退出应用；
4. 透明桌宠窗口、拖动、置顶、点击穿透与工作区边界约束；
5. 100%/125%/150%/200% 缩放、混合 DPI、多显示器和屏幕间移动；
6. 任务栏不同位置、自动隐藏、单屏和多屏；
7. Windows 虚拟桌面、普通全屏、演示/视频全屏；
8. 输入聚合、窗口上下文、截图识别与系统通知的关闭、启用、不可用和安全软件阻断状态；
9. 睡眠、唤醒、锁屏和网络断开；
10. Electron 崩溃恢复、原生模块加载失败与离线队列；
11. GPU 不可用降级；
12. 系统时间调整和 IANA 时区变化警告；
13. 键盘动作 P95 延迟；
14. 重启前后 Windows `safeStorage` 会话、SQLite、开机启动开关和采集设置连续性；
15. 未签名 Demo 被 SmartScreen 或 Defender 提示时有明确的已知限制记录，不将其表述为公开发行版本。

## 8. 实时与性能

| 项目 | 验收目标 |
|---|---|
| 好友状态端到端 P95 | ≤ 3 秒 |
| 本地键盘动作 P95 | ≤ 100ms |
| 动作更新发送频率 | 默认 ≤ 1 次/用户/秒 |
| 12 角色渲染 | ≥ 30fps |
| 60 秒无心跳 | 转离线 |
| 重连恢复 | 当前快照正确，不重放按键历史 |

压测至少覆盖每用户 100 好友、房间广播扇出和好友关系撤销。

## 9. 资产验收

自动检查 Manifest、hash、纹理尺寸、帧范围、锚点和循环；人工检查三个角色各自的 `WORK_NORMAL / SLACKING / TYPE_FRENZY`、两套共享金币特效、像素锐度、帽子 1/3/8 层及超高压力样本，以及 IP 许可记录。MVP 基线必须恰好覆盖 9 套角色动作和 2 套共享金币特效，不得用组合素材重复计算。

## 10. MVP 端到端验收剧本

1. 新用户使用用户名和密码注册登录，并设置工时、午休、日薪；
2. 创建三个待办，每次创建后自动进入 AI 建议确认页；任务列表无逐条分析按钮，并修改一个时长后点击“确认建议”；
3. 生成日程，看到一个容量冲突并确认承诺；
4. 一般工作活动保持 `WORK_NORMAL`，持续高频键盘输入触发 `TYPE_FRENZY`，娱乐浏览触发抱鱼 `SLACKING`；
5. 加好友，对方看到聚合动作但看不到任务和应用名；关闭全局活动展示及对单个好友“不对其展示”时，单向投影按规则撤销；
6. 午休余额停止增加；
7. 一位用户加班，另一位完成承诺准点跑路；
8. 结算后准点用户收到人民币窝囊费奖励，人民币分守恒检查为 0；扣减播放 `COIN_OUT`，入账播放 `COIN_IN_GLOW`，且不改变当前基础动作；
9. 两个不同工资账号购买同一帽子，扣除同等价格窝囊时长；
10. 装备三顶帽子，双方场景顺序一致；
11. 关闭截图识别，确认不再发视觉请求；活动识别页和系统托盘菜单中不存在纠正入口；
12. 分别关闭“允许好友查看我的活动状态”和“在桌面显示好友桌宠”，确认两个选项互不影响；
13. 删除好友，状态在 3 秒内撤销；
14. 登录页“金币砸脑壳”动画缺失时降级静态关键帧，登录仍可完成。

## 11. 未验证边界

以下必须在开发过程中取得真实证据，当前 PRD 不声称已验证：

- 在线视觉模型对真实办公桌面的准确率；
- 不同 Windows 版本和安全软件对输入钩子、窗口上下文、截图、开机启动和透明窗的真实行为；
- 可分享 Demo 中原生输入模块与锁定 Electron ABI、Windows x64 的兼容性；
- 混合 DPI、多显示器、虚拟桌面、全屏和任务栏组合下的窗口层级；
- 另一台 Windows 11 x64 机器上的首次启动、隐私引导、`safeStorage` 连续性与 SmartScreen/Defender 表现；
- TM 资产管线输出能否直接符合本项目 Manifest；
- 大规模奖励池的实际结算耗时；
- 不同发行地区的隐私与经济文案合规性。
